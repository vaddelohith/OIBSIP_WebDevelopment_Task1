# Portfolio Landing Page

A modern and responsive portfolio landing page built using HTML and CSS. The website features a clean dark-themed design with sections for introduction, services, projects, and contact information.

## Features

* Responsive Design
* Modern UI/UX
* Hero Section
* Services Cards
* Project Showcase
* Contact Section
* Smooth Hover Effects

## Technologies Used

* HTML5
* CSS3

## Usage

Clone the repository and open `test1.html` in your browser.
